# Job Tracker

Небольшое React-приложение для отслеживания вакансий и откликов.

Я делаю этот проект как учебный, но стараюсь строить его как настоящий маленький продукт: с маршрутизацией, общим состоянием, сохранением данных и постепенным добавлением функций.

## Что уже есть

Сейчас в приложении уже реализовано:

- overview/dashboard
- страница со всеми вакансиями
- карточки вакансий
- фильтрация по статусу
- статистика по откликам
- recent jobs на главной странице
- удаление вакансии
- сохранение вакансий в localStorage

## Что планирую доделать

Следующие шаги по проекту:

- добавление новой вакансии
- изменение статуса вакансии
- поиск по компании и позиции
- отдельная страница вакансии
- более живой и полезный dashboard
- улучшение структуры состояния
- тесты
